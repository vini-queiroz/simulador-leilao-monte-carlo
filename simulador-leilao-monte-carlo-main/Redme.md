# Simulador Monte Carlo para Leilões

Sistema de análise probabilística para operações de compra e revenda de lotes de leilão utilizando Simulação de Monte Carlo.

## Funcionalidades

- Simulação probabilística
- Distribuições:
  - Triangular
  - Normal
  - Uniforme
  - Fixa
- Análise de risco
- VaR e CVaR
- Sharpe Ratio
- Otimização automática de lance
- Fronteira risco × retorno

## Tecnologias

- Python
- NumPy
- SciPy
- Matplotlib

## Objetivo

Ajudar na tomada de decisão em operações de compra e revenda de lotes de leilão.
